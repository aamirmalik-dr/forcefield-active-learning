# Data provenance

## What the labels are, and are not

Every energy and force label in this project is a **surrogate model label**
produced by a pretrained universal potential (the "teacher"), chosen by
measured CPU speed in `data/teacher_choice.json`. The teacher was itself
trained on DFT data, but its outputs are not DFT: teacher errors against
real DFT pass straight into the students. Nothing in this repository should
be read as DFT accuracy.

Real DFT enters exactly once: the equation-of-state validation anchors for
elemental BCC Ti, Zr, Nb in `anchors_mp.json`, fetched live from the
Materials Project API (CC BY 4.0, `scripts/fetch_mp_anchors.py`, free API
key required). If no key is configured the benchmark falls back to
`anchors_literature.json`, which carries the same values as published on
the public Materials Project entry pages, with citations.

## Files

| File | What it is |
|---|---|
| `teacher_choice.json` | Measured CPU timings and provenance of both candidate teachers, and which one was chosen |
| `provenance.json` | Counts, compositions, cell sizes, seed, and labeling wall time of the generated dataset |
| `sample_frames.extxyz` | Committed sample: whole generation groups carved from the full dataset (about 300 frames) so the offline demo runs with no teacher and no download |
| `anchors_mp.json` | Real-DFT anchors fetched from the Materials Project API (CC BY 4.0) |
| `anchors_literature.json` | Keyless fallback anchors with citations |
| `full/` (gitignored) | The full labeled dataset, regenerated by `falearn generate` |

## Generation recipe

BCC supercells (16 or 54 atoms) at Vegard-rule lattice constants, random
site occupancy, 9 Ti-Zr-Nb compositions. Candidate frames come from rattle
batches at five amplitudes (0.04 to 0.28 A) and volumetric/shear strain
batches. Each batch is one generation group; splits keep whole groups and
whole compositions together (Ti2ZrNb and TiZrNb2 are never in the pool).
Candidate generation deliberately involves no teacher-driven dynamics, so
the label budget accounting stays clean: the only teacher calls are label
purchases (plus the up-front labeling of the benchmark's own test sets and
pool, which the algorithms cannot read until they purchase).

The committed sample is a carved subset of that dataset (whole groups,
capped frames per group), not a new generation run. Regenerate everything
with:

```
falearn generate --out data/full/dataset.extxyz
```

- Teacher potential: CHGNet (BSD-3-Clause, code and pretrained weights),
